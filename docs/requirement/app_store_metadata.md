### Description
Patto! is a lightweight note app designed for instant capture.
Open it fast on macOS or iOS and start typing right away.

- Create, edit, and delete notes
- Markdown input (no preview)
- Local search
- Offline-first
- Sync when signed in
- AI rewriting with your own API key
- Quick launch (macOS double-tap / iOS widget)

You can also use it locally without sync or AI features.
