# プランニングドキュメント：Patto MVP（macOS / iOS）

## 共通ルール（必読）

- 共通ルールはリポジトリルートの `AGENTS.md` を参照: `../../AGENTS.md`

## 今回の追加ルール / 例外（差分だけを書く）

- MVP対象: macOS + iOS
- AI: MVPで必須（文章編集のみ）。音声入力はMVP後。
- AI呼び出し: ユーザーAPIキー登録（端末内に保存）
- 認証: ローカル利用はログイン不要。同期を有効化する場合のみログイン必須。
- 初期同期: 同期を有効化した時、既存ローカルメモをクラウドへ自動取り込み
- クイック起動: macOSは装飾キーのダブルタップで即入力。iOSも同等に即入力導線（例: ロック画面/ウィジェット）を提供。
- クイック起動の挙動: 「新規メモ / 前回メモ」を設定で選択できる
- 同期の最新判定: `server_updated_at` を基準（端末時計ズレ対策）
- 例外: なし

## 実装モード（単独 / 並列）

- 実装モード: 並列（2ストリーム）
- 判定理由（要点だけ）:
  - ローカル機能/UI と 同期/認証 を分割できる
  - 共有境界（モデル/設定）は契約で固定してから進める

### 並列（2ストリーム）

- Stream A（ローカル）:
  - 雛形（Flutter）/ ローカルメモ（CRUD/検索/Markdown）/ 設定（AIキー、クイック起動の挙動）
  - 受け入れ条件: ログイン不要でメモ作成〜検索まで動く、即入力導線がある
- Stream B（同期）:
  - Supabase（任意ログイン）/ 同期（初期取り込み/競合）
  - 受け入れ条件: 同期ONでログイン→既存ローカルが自動アップロード→別端末で読める
