## 要件概要

### 背景・目的
- macOSで実装済みのApple Intelligence（ローカルAI）連携を、iOS 18+でも同等の体験で提供する

### 実装する機能
- **Apple IntelligenceのAPI呼び出し（iOS 18+）**
- **設定画面のApple Intelligence / 外部AI API ON/OFF**（macOSと同等挙動）
- **AI編集 / タグ提案の動作**（macOS同様のフォールバック）

### スコープ外
- iOSでの外部ペースト検知（Clipboard監視）
- iOS 18未満対応

---

## 技術選定

### 既存ライブラリの活用
- `FoundationModels`（iOS 18+）: Apple Intelligence API
- 既存の `MethodChannel` 構成を流用

---

## アーキテクチャ設計

### 方式（概要）
- Flutter ⇔ iOS は MethodChannel (`com.patto/apple_intelligence`) で連携
- iOSネイティブで `checkAvailability` / `editText` / `suggestTags` を実装
- Flutter側は `AppleIntelligenceClient` を **macOS/iOS共通**で利用

### 影響範囲（想定）
- `lib/services/apple_intelligence_client.dart`
- `lib/services/ai_service.dart`（挙動は基本同一）
- `lib/presentation/screens/settings_screen.dart`（iOS表示条件の追加）
- `ios/Runner/*`（Bridge追加・MethodChannel登録）
