### 0) 画面構成（ナビゲーション）

- 決定事項: 起動直後は常にクイックメモ画面（確定） / 検索・メモ一覧は「整理画面」として分離（確定）
- 受け入れ条件（案）:
  - アプリ起動時、最初にクイックメモが表示される
  - 整理画面（検索/メモ一覧/フォルダ整理）へ遷移できる

### 1) フォルダ機能

- 決定事項: 階層なし（確定） / 1メモ=1フォルダ（確定） / 「未分類」固定フォルダ（確定） / フォルダの作成・変更・削除（確定） / フォルダ削除は警告の上で配下メモも削除（確定） / メモのフォルダ移動（確定）
- 受け入れ条件（案）:
  - フォルダでメモを分類し、一覧で絞り込みできる
  - メモを別フォルダへ移動できる
  - フォルダ削除時は警告を出し、同意した場合のみフォルダと配下メモを削除する
- メモ:
  - 「未分類」フォルダは削除不可/名称変更不可の想定（必要なら再確認）
  - フォルダ削除の警告では「削除されるメモ件数」を表示する

### 1.1) サイドバー（フォルダ+メモ一覧）

- 決定事項:
  - メモ編集中画面の左上にサイドバー表示/非表示アイコン（確定）
  - サイドバーにはフォルダ一覧が縦に並ぶ（確定）
  - 各フォルダの右側にプルダウン（展開）アイコン（確定）
  - 展開するとフォルダ内のメモ一覧が下にスライドして表示（確定）
  - フォルダを右クリックで「名称変更/削除」（確定）
- 受け入れ条件（案）:
  - サイドバーの表示/非表示を切り替えできる
  - フォルダを展開すると、メモ一覧がアニメーション付きで表示される
  - フォルダ右クリックで名称変更/削除ができる（削除は警告あり）

## リスクと対応策（ドラフト）

- テキスト選択の取得: OS制約が強い → まずは「クリップボード経由」を第一候補として要調査
- フォルダ削除の誤操作: 影響が大きい → 警告で件数を出し、明示同意がない限り削除しない
- タブ+D&D: 実装とUIの複雑性が高い → 対象OSと最小要件（最初はmacOSのみ等）を先に確定する
- Apple Intelligence（オフライン）: 端末/OS要件がある → 対応範囲を明記し、非対応時のフォールバックを用意する
